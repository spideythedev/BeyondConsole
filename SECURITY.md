# Security

Please do not publish security vulnerabilities in public issues.

Report suspected vulnerabilities privately to **hellospideydev@gmail.com** with:
- A clear description of the affected component.
- Steps to reproduce the issue.
- The Android version and device model, if relevant.
- Any logs or proof of concept that can be shared safely.

Do not include passwords, private keys, session tokens, or personal data.

BeyondConsole is an early-stage project. Network discovery currently checks for
TCP port 9295 on the local Wi-Fi subnet. A responding port is only a candidate
and is not proof that a device is a PlayStation.
