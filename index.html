01 / About

Made for the games you already own.

BeyondConsole is an independent project focused on making console Remote Play more approachable. The console runs the game; the client aims to bring the play session to another screen.

◎

Console-first

Designed around consoles players own or are authorised to access. No game files are hosted or redistributed.

⌁

Open development

Source, decisions, documentation and issue tracking live in the public GitHub repository.

◇

Android today

The current Android shell supports local console profiles and basic network discovery. Streaming is future work.

02 / Current capabilities

What works right now.

A clear picture of what is available today, without pretending planned features are already shipped.

▣

Console profiles

Save multiple console names and local IPv4 addresses, select a profile, and remove entries. Profiles stay on your device.

⌕

LAN discovery

Scan the connected IPv4 subnet for hosts accepting TCP connections on port 9295. A match is only a candidate, not device verification.

⌁

Network status

See the active network transport and basic connection information provided by Android.

Important: Remote Play is not available yet.The app does not currently pair with PSN, authenticate with a console, negotiate a Remote Play session, decode video, play audio or transmit controller input. Do not install this expecting to stream PS5 games today.

Install guide

Open the build

Go to the Android build workflow and open the newest run marked successful.

Download the artifact

Find Artifacts at the bottom of the run page and download beyondconsole-android-debug. Sign in to GitHub if prompted.

Extract the ZIP

Use Files or your preferred archive app to extract the downloaded ZIP. Locate app-debug.apk.

Install on Android

Open the APK. If Android asks, allow your browser or file manager to install unknown apps, then continue installation.

Open BeyondConsole

Launch the app and connect your phone to the same Wi-Fi network as your console.

Add your console

Enter a label and the console's local IP address, then save the profile. This does not start a Remote Play session.

Use builds at your own discretion. Debug builds are intended for testing, may be less stable than a release, and are not signed as a public production release.

04 / First run guide

Set up a console profile.

Find the console IP

On PS5, open Settings → Network → Connection Status → View Connection Status. Note the IPv4 address.

Connect to the same Wi-Fi

Your Android device and console should be on the same reachable local network. Avoid guest Wi-Fi with client isolation.

Save a profile

Give the console a memorable name, enter its local IPv4 address, and tap Save console address.

Try local discovery

Tap Scan local network. Results only indicate a host accepted a TCP connection on port 9295; they do not prove it is a PlayStation.

Build from source

Requirements: JDK 17, Gradle 8.9 and Android SDK 35.

git clone https://github.com/spideythedev/BeyondConsole.git
cd BeyondConsole
gradle :app:assembleDebug

APK output: app/build/outputs/apk/debug/app-debug.apk.

06 / FAQ

Good to know.

Can I play PS5 games on my Android phone with this now?

Not yet. The current app is a companion shell with profiles and LAN discovery. Remote Play streaming is not implemented.

Does the scan find or verify my PlayStation?

No. It checks whether a host accepts TCP connections on port 9295. A result is only a possible match and is not identity verification.

Do I need to enter my PSN password?

No. The current app has no PSN login or account integration and does not request PSN credentials.

Where are my saved profiles stored?

On your Android device using SharedPreferences. They are not uploaded to a BeyondConsole backend.

Why can't the scan find my console?

Check that both devices share a reachable network, the console is awake, and your router does not isolate Wi-Fi clients. You can add the IP manually.

Which Android versions are supported?

Android 8.0 (API 26) and newer.

Is this an official Sony app?

No. BeyondConsole is an independent project and is not affiliated with or endorsed by Sony Interactive Entertainment.

How do I report a bug or ask for help?

Email hellospideydev@gmail.com or open an issue on GitHub.

08 / Privacy & legal

Small footprint by design.

On-device profiles

Console names and local IP addresses are stored on the device in SharedPreferences.

Local network scan

The scan makes connection attempts to local addresses on TCP port 9295. Use it only on networks you are authorised to access.

No project backend

There is no BeyondConsole account or backend service in the current app. The credits page requests public GitHub contributor metadata.
