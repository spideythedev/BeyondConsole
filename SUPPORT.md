# Support

For help, questions, or project feedback:

**Email:** hellospideydev@gmail.com

You can also open a GitHub issue for reproducible bugs and feature requests:
https://github.com/spideythedev/BeyondConsole/issues

When reporting a bug, include:
- BeyondConsole version.
- Device model and Android version.
- What you expected to happen.
- What actually happened.
- Steps to reproduce the problem.

Never post passwords, console account credentials, public IP addresses, or
private network details in a public issue.
